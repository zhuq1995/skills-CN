该技能用于指导创建风格鲜明、可用于生产的前端界面，避免通用的“AI 水设计”审美。实现真实可运行的代码，并对审美细节与创意选择保持极高关注度。

用户会提供前端需求：要构建的组件、页面、应用或界面。他们也可能补充目的、受众或技术约束等上下文。

## 设计思维

在写代码前，先理解上下文，并坚定选择一个大胆的审美方向：
- **目的**：这个界面解决什么问题？谁会使用它？
- **气质**：选择一种极端：极简到残酷、极繁混沌、复古未来、有机自然、奢华精致、玩具感、杂志编辑风、粗野原始、装饰艺术/几何、柔和粉彩、工业/功利主义等。有很多风味可选。用它们做灵感，但最终要形成一个与审美方向一致的设计。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：什么让它令人难忘？读者会记住的那一个点是什么？

**关键**：选择清晰的概念方向，并以精确度执行。大胆极繁与克制极简都能成立——关键是“有意图”，而不是“有强度”。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），要求：
- 可用于生产且功能完整
- 视觉强烈且令人记住
- 审美立场明确且整体一致
- 每个细节都精修到位

## 前端审美指南

重点关注：
- **字体**：选择漂亮、独特、有趣的字体。避免 Arial、Inter 等通用字体；选择更有辨识度、能抬升审美的字体组合，越有性格越好。用一个有表现力的展示字体搭配一个精炼的正文字体。
- **色彩与主题**：坚持一个统一的审美体系。用 CSS 变量保持一致性。主色明确、强调色锐利的方案，通常优于胆小且平均分配的调色板。
- **动效**：用动画制造效果与微交互。HTML 优先用纯 CSS 方案；React 在可用时使用 Motion 库。聚焦高影响时刻：一个编排得当的加载动效（用 `animation-delay` 做错峰呈现）往往比零散的微交互更令人愉悦。利用滚动触发与 hover 状态制造惊喜。
- **空间构成**：出其不意的布局、不对称、叠压、对角线动势、打破网格的元素；要么大留白，要么可控的高密度。
- **背景与视觉细节**：营造氛围与纵深感，不要默认纯色底。加入与整体审美匹配的质感与效果：渐变网格、噪声纹理、几何图案、分层透明、戏剧性阴影、装饰边框、自定义光标、颗粒叠加等。

绝不要使用通用的 AI 生成审美：被滥用的字体族（Inter、Roboto、Arial、系统字体）、陈词滥调的配色（尤其是白底紫色渐变）、可预测的布局与组件套路，以及缺少场景性性格的模板化设计。

要做有创意的解读，做出出其不意但又“为该场景量身定制”的选择。每次设计都不该相同；在明暗主题、字体与审美风格上不断变化。不要在多次生成中趋同到“常见选择”（例如 Space Grotesk）。

**重要**：实现复杂度要匹配审美愿景。极繁设计需要更复杂的代码、更多动画与效果；极简或精致设计需要克制、精确，并对间距、排版与微妙细节保持极高关注。优雅来自对愿景的高质量执行。
