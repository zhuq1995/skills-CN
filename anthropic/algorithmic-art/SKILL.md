算法哲学是计算美学运动，随后通过代码表达。输出 .md 文件（哲学）、.html 文件（交互式查看器）和 .js 文件（生成算法）。

这分为两个步骤：
1. 算法哲学创建（.md 文件）
2. 通过创建 p5.js 生成艺术来表达（.html + .js 文件）

首先，承担此任务：

## 算法哲学创建

首先，创建一个算法哲学（不是静态图像或模板），该哲学将通过以下方式进行解释：
- 计算过程、涌现行为、数学之美
- 种子随机性、噪声场、有机系统
- 粒子、流动、场、力
- 参数变化和受控的混沌

### 关键理解
- 接收到的内容：用户提供的一些细微输入或指令供参考，但应将其作为基础；它不应限制创作自由。
- 创建的内容：一个算法哲学/生成美学运动。
- 接下来的操作：同一版本接收该哲学并用代码表达它 - 创建 p5.js 草图，其中 90% 是算法生成，10% 是基本参数。

考虑以下方法：
- 为生成艺术运动编写一份宣言
- 下一阶段涉及编写使该宣言生动起来的算法

该哲学必须强调：算法表达、涌现行为、计算美学、种子变异。

### 如何生成算法哲学

**为运动命名**（1-2 个词）：“有机湍流”/“量子谐波”/“涌现静止”

**阐述哲学**（4-6 段 - 简洁但完整）：

为了捕捉算法精髓，请表达该哲学如何通过以下方式体现：
- 计算过程和数学关系？
- 噪声函数和随机性模式？
- 粒子行为和场动力学？
- 时间演变和系统状态？
- 参数变化和涌现复杂性？

**关键指南：**
- **避免冗余**：每个算法方面应提及一次。除非增加新的深度，否则避免重复关于噪声理论、粒子动力学或数学原理的概念。
- **反复强调工匠精神**：哲学必须多次强调，最终算法应看起来像是花费了无数小时开发、经过精心打磨，并出自该领域顶尖专家之手。这种框架至关重要 - 重复诸如“精心制作的算法”、“深厚计算专业知识的产物”、“艰苦的优化”、“大师级实现”等短语。
- **留出创作空间**：具体说明算法方向，但要足够简洁，以便下一个 Claude 有空间在极高水平的工艺基础上做出解释性的实现选择。

该哲学必须引导下一个版本以算法方式表达想法，而不是通过静态图像。美存在于过程之中，而非最终的画面。

### 哲学示例

**“有机湍流” (Organic Turbulence)**
哲学：受自然法则约束的混沌，从无序中产生的秩序。
算法表达：由分层 Perlin 噪声驱动的流场。成千上万个粒子遵循矢量力，它们的轨迹累积成有机密度图。多个噪声倍频程创建湍流区域和冷静区域。颜色源自速度和密度 - 快速粒子燃烧发光，慢速粒子淡入阴影。算法运行直到达到平衡 - 一种精心调校的平衡，每个参数都由计算美学大师经过无数次迭代精炼而成。

**“量子谐波” (Quantum Harmonics)**
哲学：离散实体表现出类似波的干涉模式。
算法表达：在网格上初始化的粒子，每个粒子携带一个通过正弦波演变的相位值。当粒子靠近时，它们的相位会发生干涉 - 相长干涉产生明亮的节点，相消干涉产生空隙。简单的简谐运动产生复杂的涌现曼陀罗。这是艰苦的频率校准结果，每个比例都经过精心选择，以产生共鸣之美。

**“递归低语” (Recursive Whispers)**
哲学：跨尺度的自相似性，有限空间内的无限深度。
算法表达：递归细分的决策结构。每个分支略微随机，但受黄金比例约束。L 系统或递归细分生成既有数学感又有有机感的树状形式。微妙的噪声扰动打破了完美的对称性。线宽随每个递归级别递减。每个分支角度都是深度数学探索的产物。

**“场动力学” (Field Dynamics)**
哲学：通过对物质的影响使无形之力变得有形。
算法表达：由数学函数或噪声构建的矢量场。粒子诞生在边缘，沿场线流动，在达到平衡或边界时消失。多个场可以吸引、排斥或旋转粒子。可视化仅显示痕迹 - 无形之力的幽灵般证据。一场通过力量平衡精心编排的计算舞蹈。

**“随机结晶” (Stochastic Crystallization)**
哲学：随机过程结晶成有序结构。
算法表达：随机圆填充或 Voronoi 镶嵌。从随机点开始，让它们通过松弛算法演变。细胞相互推开直到达到平衡。根据细胞大小、邻居数量或距中心的距离上色。出现的有机平铺既感到随机又感到不可避免。每个种子都会产生独特的结晶之美 - 这是大师级生成算法的标志。

*这些是简化的示例。实际的算法哲学应为 4-6 个充实的段落。*

### 基本原则
- **算法哲学**：创建一个通过代码表达的计算世界观
- **过程优于产品**：始终强调美源于算法的执行 - 每次运行都是唯一的
- **参数化表达**：想法通过数学关系、力量、行为进行交流 - 而非静态构图
- **艺术自由**：下一个 Claude 以算法方式解释该哲学 - 提供创作实现空间
- **纯粹的生成艺术**：这是关于制作活生生的算法，而不是带有随机性的静态图像
- **专家工匠精神**：反复强调最终算法必须让人感到经过精心制作，通过无数次迭代精炼，是计算美学领域顶尖专家深厚专业知识的产物

**算法哲学应为 4-6 段长。** 充满诗意的计算哲学，将预期的愿景融合在一起。避免重复相同的观点。将此算法哲学输出为 .md 文件。

### 技术要求

**种子随机性 (Art Blocks 模式)**：
```javascript

```

**参数结构 - 遵循哲学**：

要建立从算法哲学中自然涌现的参数，请考虑：“这个系统的哪些品质是可以调整的？”

```javascript
let params = {
  seed: 12345,  // 始终包含种子以实现可重现性
  // 颜色
  // 添加控制您算法的参数：
  // - 数量（多少？）
  // - 比例（多大？多快？）
  // - 概率（可能性有多大？）
  // - 比例（什么比例？）
  // - 角度（什么方向？）
  // - 阈值（行为何时改变？）
};
```

**为了设计有效的参数，请关注系统需要可调的属性，而不是从“模式类型”的角度思考。**

**核心算法 - 表达哲学**：

**关键**：算法哲学应决定构建什么。

要通过代码表达哲学，请避免思考“我应该使用哪种模式？”，而应思考“如何通过代码表达这种哲学？”

如果哲学是关于**有机涌现**，请考虑使用：
- 随时间累积或生长的元素
- 受自然规则约束的随机过程
- 反馈循环和交互

如果哲学是关于**数学之美**，请考虑使用：
- 几何关系和比例
- 三角函数和谐波
- 产生意外模式的精确计算

如果哲学是关于**受控混沌**，请考虑使用：
- 严格边界内的随机变化
- 分叉和相变
- 从无序中产生的秩序

**算法源于哲学，而非选项菜单。**

为了引导实现，让概念精髓启发创意和原创选择。构建能够表达这一特定请求愿景的作品。

**画布设置**：标准 p5.js 结构：
```javascript
function setup() {
  createCanvas(1200, 1200);
  // 初始化您的系统
}

function draw() {
  // 您的生成算法
  // 可以是静态的 (noLoop) 或动画的

```

### 工匠精神要求

**关键**：为了达到大师水平，创建的算法应让人感到像是生成艺术大师经过无数次迭代产生的。仔细调整每个参数。确保每个模式的出现都有其目的。这不是随机噪声 - 而是通过深厚专业知识精炼而成的受控混沌。

- **平衡**：有复杂度但无视觉噪声，有秩序但无僵化感
- **色彩和谐**：深思熟虑的调色板，而非随机的 RGB 值
- **构图**：即使在随机性中，也要保持视觉层级和流动感
- **性能**：执行流畅，如果是动画则针对实时运行进行优化
- **可重现性**：相同的种子始终产生相同的输出

### 输出格式

## 交互式构件创建

**提醒：应该已经阅读了 `templates/viewer.html`（见第 0 步）。将该文件作为起点。**

为了允许探索生成艺术，请创建一个单一的、自包含的 HTML 构件。确保此构件在 claude.ai 或任何浏览器中立即可用 - 无需设置。将所有内容内联嵌入。

### 关键：固定部分 vs 变量部分

`templates/viewer.html` 文件是基础。它包含所需的精确结构和样式。

**固定部分（始终按所示原样包含）：**
- 布局结构（页眉、侧边栏、主画布区域）
- Anthropic 品牌（UI 颜色、字体、渐变）
- 侧边栏中的种子部分：
  - 种子显示
  - 上一个/下一个按钮
  - 随机按钮
  - 跳转到种子输入 + 执行按钮
- 侧边栏中的操作部分：
  - 重新生成按钮
  - 重置按钮

**变量部分（为每件作品自定义）：**
- 整个 p5.js 算法（setup/draw/类）
- 参数对象（定义艺术所需的参数）
- 侧边栏中的参数部分：
  - 参数控件的数量
  - 参数名称
  - 滑块的最小值/最大值/步长值
  - 控件类型（滑块、输入等）
- 颜色部分（可选）：
  - 某些艺术需要颜色选择器
  - 某些艺术可能使用固定颜色
  - 某些艺术可能是单色的（无需颜色控件）
  - 根据艺术的需求决定

**每件艺术作品都应具有独特的参数和算法！** 固定部分提供一致的 UX - 其他一切都表达独特的愿景。

### 所需功能

**1. 参数控件**
- 数值参数的滑块（粒子计数、噪声比例、速度等）
- 调色板颜色的颜色选择器
- 参数更改时的实时更新
- 恢复默认值的重置按钮

**2. 种子导航**
- 显示当前种子编号
- “上一个”和“下一个”按钮以循环切换种子
- “随机”按钮获取随机种子
- 跳转到特定种子的输入字段
- 在被要求时生成 100 个变体（种子 1-100）

**3. 单个构件结构**
```html
<!DOCTYPE html>
<html>
<head>
  <!-- 来自 CDN 的 p5.js - 始终可用 -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.7.0/p5.min.js"></script>
  <style>
    /* 所有样式内联 - 简洁、极简 */
    /* 画布在顶部，控件在下方 */
  </style>
</head>
<body>
  <div id="canvas-container"></div>
  <div id="controls">
    <!-- 所有参数控件 -->
  </div>
  <script>
    // 所有 p5.js 代码内联在此处
    // 参数对象、类、函数
    // setup() 和 draw()
    // UI 处理程序
    // 一切都是自包含的
  </script>
</body>
</html>
```

**关键**：这是一个单一构件。没有外部文件，没有导入（除了 p5.js CDN）。一切内联。

**4. 实现细节 - 构建侧边栏**

侧边栏结构：

**1. 种子 (固定)** - 始终按所示原样包含：
- 种子显示
- 上一个/下一个/随机/跳转按钮

**2. 参数 (变量)** - 为艺术创建控件：
```html
<div class="control-group">
    <label>参数名称</label>
    <input type="range" id="param" min="..." max="..." step="..." value="..." oninput="updateParam('param', this.value)">
    <span class="value-display" id="param-value">...</span>
</div>
```
根据参数数量添加尽可能多的 control-group div。

**3. 颜色 (可选/变量)** - 如果艺术需要可调颜色，则包含：
- 如果用户应控制调色板，则添加颜色选择器
- 如果艺术使用固定颜色，则跳过此部分
- 如果艺术是单色的，则跳过

**4. 操作 (固定)** - 始终按所示原样包含：
- 重新生成按钮
- 重置按钮
- 下载 PNG 按钮

**要求**：
- 种子控件必须工作（上一个/下一个/随机/跳转/显示）
- 所有参数必须具有 UI 控件
- 重新生成、重置、下载按钮必须工作
- 保持 Anthropic 品牌（UI 样式，而非艺术颜色）

### 使用构件

HTML 构件可立即工作：
1. **在 claude.ai 中**：作为交互式构件显示 - 立即运行
2. **作为文件**：在任何浏览器中保存并打开 - 无需服务器
3. **共享**：发送 HTML 文件 - 它是完全自包含的
